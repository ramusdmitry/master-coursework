## Расчёт докачки 1s (калибровка: 103 байт/бар)

### Вариант B — субминутные за ВЕСЬ период 2021-2025
| | объём |
|---|---|
| 1 актив 1s (4.7 года): | 150M баров, 15.4 ГБ CSV |
| 5 активов: | ~20 ГБ download, ~77 ГБ CSV (диск свободен 916 ГБ ✅) |
| **RAM (прямой подход):** | ~46 ГБ/актив — ❌ не влезает в 28 ГБ |
| **RAM (stream-resample):** | **~2.1 ГБ (пик = 1 месяц)** — ✅ влезает в любой период |

**Решение RAM — `download_subminute.py`:** качаем 1s по ОДНОМУ месяцу → ресемпл сразу
в {1s,5s,15s,30s} → дописываем на диск → выбрасываем месяц. Пик RAM не зависит от
длины периода (замерено: 2.1 ГБ на месяц ETH). Значит весь период 2021-2025 теперь
RAM-выполним; лимит — диск (есть) и время (~3 ч на 5 активов), не память.

## Вывод

- **Полное покрытие крупных tf (1m-1h) уже есть** — ничего докачивать не нужно.
- **Субминутные по всем 5 активам докачиваются** через stream-resample. Сейчас качаем
  2025 (совпадает с покрытием BTC). Весь период (2021-2025) тоже выполним (RAM решён),
  но субминутные — микроструктура (Sharpe −27…−852, не торгуемо), edge не дадут.
- Поэтому докачка субминутных — ради полноты картины, не ради edge. Реальный edge
  остаётся на 1h (BTC 1h + order-flow, 6/9 walk-forward).
